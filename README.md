# CalcMatCat
CalcMatCat és una aplicació web creada per Bernat Marquilles per generar fitxes d'operacions matemàtiques (sumes, restes i multiplicacions) en PDF per a alumnes. Permet configurar el nombre de xifres (1 a 4), opció de portant/sense portant, quantitat d'operacions, espai per al nom/data i full de solucions customizable.
