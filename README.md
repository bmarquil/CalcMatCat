## 📌 Què és CalcMatCat?

**CalcMatCat** és una aplicació web intuïtiva i personalitzable dissenyada per a mestres, educadors i famílies. Permet generar fitxes de matemàtiques a mida per a alumnes en edat escolar, llistes per imprimir o descarregar directament en format **PDF**.

L'objectiu principal és facilitar la creació d'exercicis de càlcul mental i escrit de manera ràpida, adaptable al nivell de cada estudiant.

---

## ✨ Característiques Principals

- ➕ **Tipus d'operacions:** Sumes, restes, multiplicacions o mode barrejat (mix).
- 🔢 **Nivell adaptable:** Trieu el nombre de xifres per a les operacions (de 1 a 4 xifres).
- 💡 **Gestió de dificultat (Portant / Sense portant):** Opció per seleccionar si les sumes i restes tenen o no portant.
- 📐 **Disseny autoadaptable:** L'amplada de les línies i columnes d'operació s'ajusta automàticament segons el nombre de xifres.
- 📝 **Capçalera personalitzada:** Espai per a que l'alumne/a escrigui el seu nom i la data.
- 📑 **Full de solucions opcional:** Inclou una segona pàgina amb les solucions automàtiques per a una correcció ràpida.
- 🖨️ **Exportació directa:** Descàrrega en PDF d'alta qualitat o impressió directa des del navegador.

## 🚀 Com fer servir CalcMatCat

No requereix cap mena d'instal·lació de servidors ni de llibreries complexes. És una aplicació **frontend 100% autònoma**.

### Opció 1: En línia (GitHub Pages)
Només cal que obris el repositori i facis clic a l'enllaç de **GitHub Pages** per fer-la servir directament des del navegador.

### Opció 2: En local
1. Clona aquest dipòsit o descarrega el codi font:
   ```bash
   git clone https://github.com/el-teu-usuari/CalcMatCat.git
   ```
2. Obre el fitxer `index.html` directament al teu navegador preferit (Chrome, Firefox, Safari, Edge).

## 🛠️ Tecnologies utilitzades

- **HTML5 & JavaScript (ES6+):** Lògica generadora de nombres aleatoris, control de portants i renderitzat dinàmic.
- **[Tailwind CSS](https://tailwindcss.com/):** Estils moderns, nets i adaptables (*responsive*).
- **[html2pdf.js](https://eekohe.github.io/html2pdf.js/):** Conversió d'elements HTML a fitxers PDF directament des del navegador del client.
- **FontAwesome:** Iconografia.
